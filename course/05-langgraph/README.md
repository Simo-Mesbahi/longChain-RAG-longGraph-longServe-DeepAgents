# Module 05 - LangGraph

> Statut : planifie.

Ce module introduira les graphes stateful : etat, noeuds, aretes, conditions, boucles, persistance, streaming et interruptions.

## Mini-projet

Orchestrer un dossier selon le chemin `analyser -> rechercher -> verifier -> repondre`, avec validation humaine lorsque les preuves sont insuffisantes.

## Objectif d'architecture

Distinguer les chemins deterministes, imposes par le code, des decisions dynamiques confiees au modele.
