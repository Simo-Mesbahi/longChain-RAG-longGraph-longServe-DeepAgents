# Module 09 - Projet final

> Statut : planifie.

Le projet final reunira LangChain, RAG, LangGraph, LangSmith et Deep Agents dans un assistant d'investigation documentaire en assurance.

## Exigences minimales

- reponses fondees sur des passages cites ;
- refus lorsque les preuves sont insuffisantes ;
- sorties typees ;
- workflow stateful et validation humaine ;
- traces et evaluation reproductible ;
- API testee et documentation d'architecture ;
- limites, securite et couts explicitement analyses.

Le systeme aidera a prioriser une investigation. Il ne prendra pas seul une decision de fraude.
