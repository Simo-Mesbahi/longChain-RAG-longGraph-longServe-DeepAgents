# Module 02 - Sorties structurees et outils

> Statut : planifie.

Ce module transformera une reponse textuelle fragile en objet valide par Pydantic. Il couvrira `with_structured_output`, le tool calling, la validation, les erreurs, les retries et les timeouts.

## Mini-projet

Extraire une demande d'assurance vers un schema type, signaler les champs manquants et refuser les valeurs incoherentes.

## Prerequis

Terminer les modules 00 et 01 et executer `structured_output_preview.py`.
