# Module 07 - Deep Agents

> Statut : planifie.

Ce module abordera les taches longues, la planification, la gestion du contexte par fichiers, les sous-agents, la memoire et les skills.

## Mini-projet

Construire un agent d'analyse multi-documents qui delegue la recherche, la verification et la synthese a des sous-agents specialises.

## Securite

Toute execution de code ou manipulation de fichiers sera limitee par des permissions explicites et, lorsque necessaire, un environnement sandboxe.
