# Module 08 - Production et migration LangServe

> Statut : planifie.

LangServe est deprecie pour les nouveaux projets. Ce module l'etudiera pour comprendre et migrer les applications existantes, puis presentera les options actuelles de deploiement et d'observabilite.

## Sujets

- contrats API et validation ;
- authentification et gestion des secrets ;
- traitement asynchrone et files de taches ;
- cout, latence et limites de debit ;
- migration depuis une ancienne API LangServe ;
- CI/CD, monitoring et procedures de retour arriere.
