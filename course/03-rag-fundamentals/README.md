# Module 03 - Fondamentaux RAG

> Statut : planifie.

Ce module construira un pipeline complet : chargement, nettoyage, decoupage, embeddings, indexation, retrieval et generation avec citations.

## Mini-projet

Creer un assistant qui repond a partir de documents publics et indique explicitement lorsqu'aucune preuve suffisante n'est retrouvee.

## Critere central

Une bonne reponse ne compensera jamais un mauvais retrieval. Le retrieval et la generation seront donc evalues separement.
