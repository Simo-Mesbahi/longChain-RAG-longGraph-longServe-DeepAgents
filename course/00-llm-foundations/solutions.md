# Corrections - Module 00

## Prompt ameliore

```text
Tu es un formateur en intelligence artificielle.
Explique le RAG a un Data Scientist junior en 180 mots maximum.
Structure la reponse en quatre parties : definition, pipeline, exemple et limites.
N'affirme pas qu'un RAG elimine toutes les hallucinations.
```

## Pourquoi cette version est meilleure

- le role donne une orientation ;
- le public fixe le niveau technique ;
- le format rend la sortie plus facile a verifier ;
- la contrainte sur les limites evite une promesse incorrecte.

Ce prompt ne garantit toujours pas la veracite. Une application serieuse doit ajouter des tests et, selon le cas, des sources controlees.
