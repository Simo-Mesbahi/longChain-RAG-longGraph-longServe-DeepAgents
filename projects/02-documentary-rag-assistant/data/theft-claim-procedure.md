# Procedure Asteria - Sinistre vol et vandalisme

> Document pedagogique fictif. Les regles ci-dessous sont destinees au projet de cours.

## Declaration du vol

Un vol doit etre declare dans les deux jours ouvres suivant sa decouverte. Le depot de plainte
est requis pour ouvrir l'instruction. Si le depot de plainte n'est pas encore disponible, le
gestionnaire peut enregistrer le dossier mais doit demander le justificatif avant toute decision
d'indemnisation.

La declaration doit preciser la date de decouverte, l'adresse du logement, les traces d'effraction,
la liste des biens voles ou endommages, et les mesures prises pour securiser le logement.

## Preuves de possession

Les preuves recevables incluent les factures, garanties, photographies datees, expertises,
releves bancaires ou certificats d'authenticite. Pour les objets de valeur, une declaration
prealable dans les conditions particulieres peut etre necessaire.

Une simple liste de biens sans preuve ne suffit pas pour determiner le montant indemnisable.
Le gestionnaire doit demander des complements, prioriser les biens les mieux documentes et tracer
les pieces utilisees pour chaque montant retenu.

## Vandalisme et effraction

Les dommages lies a l'effraction, comme une porte forcee ou une serrure endommagee, sont analyses
avec les devis de remise en etat. Les reparations d'urgence peuvent etre prises en compte si elles
sont proportionnees et justifiees.

Si aucune trace d'effraction n'est observee, le dossier n'est pas automatiquement refuse. Il doit
etre analyse avec le depot de plainte, les circonstances declarees, les garanties souscrites et
les exclusions applicables.
