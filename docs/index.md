# De LangChain aux Deep Agents

Ce cours apprend a construire des applications LLM utiles, mesurables et controlables. Il part des bases et progresse vers le RAG, LangGraph, LangSmith et les Deep Agents.

## A qui s'adresse ce cours ?

- aux developpeurs Python qui decouvrent les LLM ;
- aux Data Scientists qui veulent industrialiser leurs prototypes ;
- aux profils IA qui veulent comprendre les architectures agentiques modernes.

## Promesse pedagogique

Vous ne vous contenterez pas de recopier des notebooks. Chaque module relie la theorie a une implementation, puis a des criteres de qualite observables.

Commencez par [l'installation](getting-started.md), puis suivez le [programme](curriculum.md).
